file_browser.lua

Classes and functions defined:
  • FilteredFileTreeNode class - A tree node representing a file (or directory) in the physical file-system that meets a given file extension criterion.
  • FilteredTreeControl class - A sortable tree control that accommodates a certain file type and also possibly shows their last modification dates.
  • UIFileBrowser class - A file browser with a scrollbar. Used by load_game and save_game.
