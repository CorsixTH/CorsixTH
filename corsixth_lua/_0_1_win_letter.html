function WinLetter:WinLetter(app, paragraphs, choose)

Load the letter's graphics and take its paragraphs. The paragraphs go on the paper below the letter head, in Font35V in the movie's own palette (winlevel.pl8), with a blank line between them. They are laid out for the screen when the letter is drawn. If the font cannot be loaded, the letter has no font and is not shown.

Parameters:

Name Type Description
app App the app
paragraphs string the paragraphs
choose function called with the answer (1 tick, 2 cross); without it the letter has no buttons

function WinLetter:onMouseDown(button, x, y)

A mouse button is pressed on the movie. While the letter is being typed, a left click finishes it. Once it is typed, a left press on a button holds it down until the release (onMouseUp), and a click anywhere else does nothing; a letter without buttons leaves the click to the movie. Before a letter with buttons shows, a click does nothing.

Parameters:

Name Type Description
button string the mouse button ("left", "right", ...)
x number x on the screen
y number y on the screen
 Returns:
Type Description
boolean # true if the letter took the click (the movie goes on)
