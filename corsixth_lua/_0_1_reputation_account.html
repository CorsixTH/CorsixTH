ReputationAccount Class

The weighted reputation accounting of the original game: credit and weight accumulate, and the visible rating is derived as clamp(trunc(500*credit/weight)).

function ReputationAccount.eventDelta(event, weight, amount)

The change an event makes to the accounting. The delta is calculated from the weight *before* the event, and it is returned rather than applied so that the same figure can be given to the hospital and, when the event names a disease, to that disease. Their two histories differ, so the same delta produces two different rating changes. The weight to scale from is the caller's choice. Percentage events use the hospital's weight.

Parameters:

Name Type Description
event integer The event identifier, 0 to 24
weight integer The weight to scale a percentage event from
