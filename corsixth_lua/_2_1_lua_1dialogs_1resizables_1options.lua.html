options.lua

Classes and functions defined:
  • UIOptions class - Options window used in the main menu and ingame.
  • UIResolution class - A custom resolution selection window
  • UIScrollSpeed class - A window for setting the scroll speed of the camera.
  • UIShiftScrollSpeed class - A window for setting the scroll speed of the camera while pressing the SHIFT key..
  • UIZoomSpeed class - Window to set the zoom speed of the scroll wheel while in-game.
  • height_textbox_reset function - persistable:options_height_textbox_reset
  • language_button function - persistable:options_window_language_button
  • width_textbox_reset function - persistable:options_width_textbox_reset
