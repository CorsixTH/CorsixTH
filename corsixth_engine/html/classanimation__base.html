◆ scale_factor

int animation_base::scale_factor {1}
protected

Scale factor for the animation.

For both animation and sprite_render_list scale_factor is currently only implemented for drawing. Support for hit_test should be implemented if a need to hit_test on a scaled sprite_render_list or animation arises.

In all cases scale_factor is not persisted, and expected to be set according to the current game options before calling draw.
